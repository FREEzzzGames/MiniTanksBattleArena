# IRON FRONT — браузерная танковая игра

Самостоятельная браузерная игра на HTML Canvas 2D, рассчитанная в первую очередь на сенсорные экраны. APK не собирается.

## Управление
- Коснитесь поля боя и удерживайте палец, чтобы двигаться к выбранной точке. Виртуального джойстика нет.
- Удерживайте **ОГОНЬ** для стрельбы; отпускание прекращает стрельбу.
- **ДЫМ** выпускает дымовую завесу.
- **ЦЕЛЬ** переключает видимого противника для автоматического наведения.
- **УКРЫТЬСЯ** направляет танк к укрытию относительно ближайшего противника.
- **ОТРЯД** переключает приказы союзникам.
- Пауза приостанавливает бой; меню позволяет начать заново или продолжить.

## Проверки и публикация
Каждый push в `main`, затрагивающий игру, тесты или workflow, запускает браузерные smoke-тесты на Chromium. Публикация GitHub Pages выполняется только после успешного прохождения тестов.
